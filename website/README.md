# website

Public marketing site for **Browsy**.

This is the public home of the product. The browser extension is not built in this folder.

## Stack

- Next.js
- TypeScript
- Tailwind CSS

## Run locally

From this directory:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm start` — serve the production build
